# GitHub Avatar Generator

Скрипт создаёт уникальные аватары (identicon) в виде симметричных узоров с цветом.
Каждый запуск генерирует **10 случайных аватаров** без каких-либо настроек и вопросов.

## Зачем это нужно

- **Аватар для проекта или бота**, если нет логотипа или желания рисовать его вручную.
- **Заглушки для интерфейсов**: вместо серого силуэта у пользователя без фото.
- **Демо-данные**: быстро получить набор разных картинок для макетов, тестов или презентаций.
- **Аватар по строке**: функцию `build_png(grid, color, ...)` можно вызывать с логином или email, и аватар будет одинаковым для одной строки.

## Возможности

- Ровно 10 случайных аватаров за один запуск.
- Симметричный узор 5×5, похожий на стандартные identicon GitHub.
- Два формата: **PNG** (для загрузки на GitHub) и **SVG** (векторный, масштабируется без потерь).
- Без аргументов командной строки и без меню.
- **Без сторонних библиотек**: только стандартный модуль Python.

## Требования

- Python 3.8 или новее.

Установка дополнительных пакетов не нужна.

## Запуск

```bash
git clone https://github.com/your-name/github-avatar-generator.git
cd github-avatar-generator
python github_avatar.py
```

После запуска в папке `avatars/` появятся файлы вида:

```
avatars/avatar_01_3f9a2c1b.png
avatars/avatar_01_3f9a2c1b.svg
...
avatars/avatar_10_c04d8e77.png
avatars/avatar_10_c04d8e77.svg
```

## Настройка

Все параметры находятся в начале файла `github_avatar.py`:

| Константа | По умолчанию | Описание |
|---|---|---|
| `COUNT` | `10` | Количество аватаров |
| `SIZE` | `420` | Размер изображения в пикселях |
| `CELLS` | `5` | Размер сетки (нечётное число, не меньше 3) |
| `OUT_DIR` | `avatars` | Папка для сохранения |
| `BACKGROUND` | `(0xF6, 0xF8, 0xFA)` | Цвет фона в формате RGB |

## Как установить аватар на GitHub

1. Запустите скрипт и откройте папку `avatars/`.
2. Выберите понравившийся файл `.png`.
3. Откройте GitHub → **Settings** → **Public profile**.
4. Нажмите на текущее фото и загрузите PNG.

> GitHub не принимает SVG для аватара профиля, поэтому используйте PNG.

## Как это работает

1. Генерируется случайная строка из 16 шестнадцатеричных символов.
2. Строка превращается в хэш SHA-256.
3. Первые три байта хэша задают цвет в модели HSL.
4. Следующие байты определяют, какие клетки левой половины сетки заполнены.
5. Правая половина является зеркальным отражением левой, поэтому узор симметричен.
6. Сетка рисуется в пиксели, которые упаковываются в PNG с помощью `zlib`. SVG создаётся из тех же данных.
